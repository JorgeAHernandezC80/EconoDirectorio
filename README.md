# EconoDirectorio — Economía Popular

Directorio digital de negocios de economía popular.

## Estructura del proyecto

```
/
├── index.html        ← App principal (todo en un solo archivo)
├── netlify.toml      ← Configuración de Netlify
└── README.md         ← Este archivo
```

## Cómo actualizar

1. Edita `index.html` con los cambios
2. Haz `git add . && git commit -m "descripción del cambio"`
3. Haz `git push`
4. Netlify despliega automáticamente en segundos

## Tecnologías

- React 18 (via CDN, sin build)
- Babel Standalone (transpila JSX en el navegador)
- CSS puro con variables
- Fuentes: Newsreader · Geist · JetBrains Mono

## URL en producción

Disponible en tu subdominio de Netlify después del primer deploy.
